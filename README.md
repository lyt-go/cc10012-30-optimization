# 数据查询探索与自助分析平台

面向数据查询编辑器、可视化探索、自助分析看板、数据导出分发、分析笔记协作与查询历史管理的本地化数据分析应用平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/api/tag-service.ts     标签使用统计：关系账本、频次重算、标签化数据集发布
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/data/tag-store.ts      标签关系 / 使用明细 / 版本快照的持久化
│   ├── src/data/tag-types.ts      标签统计与标签化数据集的类型
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 标签使用频次与标签化数据集

「标签分类」与「分析笔记」通过一份**标签化数据集**联动，频次重算的口径如下：

- **关系是唯一登记**：一条「标签 + 数据集」关系只保留一条最近使用明细；重复写入同一关系会
  合并到这条明细上（`mergedWrites` 与 `history` 留痕），关系数、使用频次、最后使用时间都不变。
  已移除的关系再写入会被拒绝，旧关系不再累加最后使用时间；需要重新使用时点「重新登记关系」，
  会生成新的关系版本 `rN` 与新的使用明细。
- **频次口径**：`使用频次 = 有效关系条数 = 有效明细条数`，
  `最后使用 = 这些明细中最晚的 occurredAt`。两者在同一次发布中一起写入标签定义与标签化数据集，
  所以页面上可以按「标签名称 / 使用频次 / 最后使用」逐项比对。
- **按版本发布**：重算只会生成新版本（`v1`、`v2`…），每个版本保存关系、明细、标签定义来源快照
  与校验指纹，可回查历史版本。分析笔记始终读取**最新已发布版本**：重算进行中或重算中断时，
  继续显示上一份完整结果，不会读到零频次、空标签或半成品缓存。
- **只补变化**：关系新增 / 移除、数据集迁移、标签增删、标签定义被改动、笔记关联变化都会登记为
  待重算变更；重算中断后再次运行只补齐未完成项，已完成项沿用上一份完整版本。
- **可核验**：标签分类页「标签化数据集」标签页提供「逐项核验」，覆盖快照内部（频次 = 明细数、
  最后使用 = 明细最晚时间）、标签定义（名称 / 频次 / 最后使用）、实时明细（未重算时标记为预期差异）
  与校验指纹四类检查，并可导出 CSV。

手动验证路径：

1. 打开「标签分类 → 关系与使用登记」，对已有关系点「再记一次使用」，回到「标签化数据集」确认
   频次与最后使用时间都不变，明细的「合并写入」次数 +1。
2. 新增一条关系后，打开「分析笔记」确认排序随最高频次变化；同一份标签的频次与最后使用时间
   与标签分类页一致。
3. 在「频次重算」里取消自动重算、新登记几条关系后点「模拟中断（处理 1 项后停下）」，
   分析笔记仍显示上一份完整版本；点「继续重算（只补缺口）」后只处理剩余项并发布新版本。
4. 删除标签或在「关系与使用登记」里迁移数据集，重算后旧关系不再出现在标签化数据集中，
   分析笔记排序来自新完整结果。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-explore-selfservice:entries` 这一项，或调用 `resetModule(模块)`。
